|     |                                       | In the case where no vuln was found, a client might prefer a simple "No Vulnerability was Found" with no technical details of the steps we did.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

|     |                                       | **Example**: A hospital may not care that their Internet-facing login portal accepts TLS 1.0 ciphers. An eCommerce site is likely to be much more concerned, given the PCI violation that accepting TLS 1.0 creates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|     |                                       |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 3   | Tailor the Content                    | Consider which group of your client is reading the report, don't include a report that is too technical for management level but prepare a separate section for the developing team as well.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|     |                                       |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## Testing Environment Considerations
| #   | **CUES & QUESTIONS**                                           | NOTES-------------------------------------------------                                                                                                                                                                                                                                                                                                                                                                                        |
| --- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Why should you include the Testing Environment Considerations? | We need to inform the client of extenuating circumstances to ensure transparency. Any issues faced, limitations, or other important things to note are included here.                                                                                                                                                                                                                                                                         |
|     |                                                                | **Positive Outcome**: "There were no limitations or extenuating circumstances in the engagement. The time allocated was sufficient to thoroughly test the environment."                                                                                                                                                                                                                                                                       |
|     |                                                                | **Neutral Outcome**: "There were no credentials allocated to the tester in the first two days of the test. However, the attack surface was much smaller than anticipated. Therefore, this did not have an impact on the overall test. OffSec recommends that communication of credentials occurs immediately before the engagement begins for future contracts, so that we can provide as much testing as possible within the allotted time." |
|     |                                                                | **Negative Outcome**: "There was not enough time allocated to this engagement to conduct a thorough review of the application, and the scope became much larger than expected. It is recommended that more time is allocated to future engagements to provide more comprehensive coverage."                                                                                                                                                   |

|     |                                                 | Next, explain why this is dangerous, bonus points if it is in the context of the application.                                                                |
|     |                                                 | Finally, include what an attacker can accomplish with it.                                                                                                    |
|     |                                                 | make sure that the description is written in a way that show immediate impact.                                                                               |

## Summary

Note Taking and Reporting for a penetration tester is one of the most crucial task that needs to be mastered by an aspiring Penetration Tester. Being able to take notes effectively during testing by utilising the right tools will help report making so much smoother. When writing reports, a lot need to be taken into consideration such as the audience, language, evidences, references, screenshots, etc. Reports have to be able to give management level an idea of what to do next and technical teams understanding of how to strengthen their application so a balance of both is important.
