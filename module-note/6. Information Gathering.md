| What is a [DNS](https://www.cloudflare.com/learning/dns/what-is-dns/) and how can we enumerate it.                                                                                                                              | DNS Stands for Domain Name System and essentially it is a public database used to translate human readable addresses (domain names) to IP addresses.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                 | Each domain can use different types of DNS records, some of the most common types are:<br>- **NS**: Nameserver records contain the name of the authoritative servers hosting the DNS records for a domain.<br>- **A**: Also known as a host record, the "_a record_" contains the IPv4 address of a hostname (such as www.megacorpone.com).<br>- **AAAA**: Also known as a quad A host record, the "_aaaa record_" contains the IPv6 address of a hostname (such as www.megacorpone.com).<br>- **MX**: Mail Exchange records contain the names of the servers responsible for handling email for the domain. A domain can contain multiple MX records.<br>- **PTR**: Pointer Records are used in reverse lookup zones and can find the records associated with an IP address.<br>- **CNAME**: Canonical Name Records are used to create aliases for other host records.<br>- **TXT**: Text records can contain any arbitrary data and be used for various purposes, such as domain ownership verification. |
