# Examples of using `gobuster`

# Gobuster Cheatsheet

## Modes
- `dir`  — directory/file brute-forcing
- `dns`  — subdomain brute-forcing
- `vhost` — virtual host brute-forcing
- `fuzz` — generic fuzzing (URL, headers, etc.)
- `s3`   — open S3 buckets
- `tftp` — TFTP enumeration

## Directory/File Enumeration
```bash
gobuster dir -u http://10.10.10.10 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt

Common flags:

┌─────────────┬────────────────────────────────────────────────────────────────────┐
│    Flag     │                              Purpose                               │
├─────────────┼────────────────────────────────────────────────────────────────────┤
│ -u          │ Target URL                                                         │
├─────────────┼────────────────────────────────────────────────────────────────────┤
│ -w          │ Wordlist path                                                      │
├─────────────┼────────────────────────────────────────────────────────────────────┤
│ -x          │ File extensions (e.g. -x php,txt,html)                             │
├─────────────┼────────────────────────────────────────────────────────────────────┤

├─────────────┼────────────────────────────────────────────────────────────────────┤
│ -o          │ Output to file                                                     │
├─────────────┼────────────────────────────────────────────────────────────────────┤

├─────────────┼────────────────────────────────────────────────────────────────────┤

Virtual Host Enumeration

gobuster vhost -u http://example.com -w /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-5000.txt
Add --append-domain if the wordlist has bare words (no domain suffix).

Useful Kali Wordlist Paths

(SecLists may need: sudo apt install seclists → lives in /usr/share/seclists/)
/usr/share/dirb/wordlists/big.txt

OSCP Tips

- Always try common.txt first (fast), then escalate to directory-list-2.3-medium.txt or SecLists raft-medium if nothing found.
- Add -x php,txt,html,bak,zip when you know/suspect the tech stack — saves time vs guessing extensions after the fact.
- Use -b "" (empty blacklist) if the target returns weird custom status codes and gobuster filters too aggressively.
- Pair with -t 50 on OSCP labs for speed, but drop threads if the target rate-limits/blocks you.
- If gobuster reports a flood of false positives, check for a wildcard/catch-all response (soft 404) — you may need --exclude-length or switch wordlists.
## Using `gobuster` with pattern
```


Create pattern file with these
```
{GOBUSTER}/v1
{GOBUSTER}/v2
```
Use `gobuster` on target with big.txt wordlist, gobuster will replace {GOBUSTER} with common words in big.txt

kali@kali:~$ gobuster dir -u http://192.168.50.16:5002 -w /usr/share/wordlists/dirb/big.txt -p pattern
